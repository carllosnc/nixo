Projetado para controle total da sua mídia

Cada detalhe do Nixo foi idealizado para entusiastas de áudio e vídeo que não toleram lentidão e desejam precisão milimétrica.

Modo Picture-in-Picture

Janela flutuante com opção Always on Top, arrasto livre por toda a tela e restauração rápida com duplo clique.

Playlist Virtualizada O(1)

Painel lateral com animação fluida capaz de carregar mais de 10.000 itens sem perda de quadros e ordenação alfanumérica inteligente.

Equalizador de Vídeo

Ajuste em tempo real de Brilho, Contraste, Saturação e Gama através de shaders dedicados acelerados por GPU.

Legendas com Drag & Drop

Arraste arquivos de legenda (.srt, .ass, .vtt) diretamente para o player com personalização de tipografia e sincronia milimétrica.

Captura de Tela Sem Perdas

Gere capturas do quadro exato em resolução nativa sem compressão, copiando diretamente para a área de transferência.

Motor Sintético Integrado

Gerador procedural de sinal de teste a 60 FPS acelerado por shader, permitindo testar toda a interface sem codecs externos.

Cargo Workspace

Arquitetura Modular em Rust

O projeto é desacoplado em crates reutilizáveis, garantindo isolamento estrito entre o backend de mídia, os drivers de GPU e o loop de renderização do egui.

folder_open
nixo-core

Modelos de domínio puros, máquina de estados de reprodução (Playing, Paused, Idle), fila de comandos e abstração MediaBackend.

settings_input_component
nixo-engine

Integração dinâmica com libmpv em tempo de execução sem requerer headers C no build. Worker de thumbnails com cache local em disco.

desktop_windows
nixo-app

Interface GUI nativa compilada com egui + wgpu. Barra OSD anti-colisão responsiva em 4 níveis e internacionalização nativa (i18n).

Instalação sem Complicações

Execute em Menos de 30 Segundos

Como o Nixo carrega a libmpv dinamicamente, você não precisa de SDKs de C, compilações demoradas ou configurações de ambiente complexas.

nixo-setup-terminal
# 1. Clone o repositório oficial do Nixo
git clone https://github.com/carllosnc/nixo.git
cd nixo
# 2. Baixe automaticamente a libmpv-2.dll para vendor/mpv/
.\scripts\setup-mpv.ps1
# 3. Compile e rode o player nativo em modo release
cargo run --release -p nixo-app
# 1. Instale dependências gráficas e libmpv-dev
sudo apt-get install libgtk-3-dev libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev libwayland-dev libmpv-dev
# 2. Clone e execute o player
git clone https://github.com/carllosnc/nixo.git && cd nixo
cargo run --release -p nixo-app
# 1. Instale o mpv via Homebrew
brew install mpv
# 2. Execute via Cargo com Metal backend
git clone https://github.com/carllosnc/nixo.git && cd nixo
cargo run --release -p nixo-app
